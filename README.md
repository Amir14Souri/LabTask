# Machine Unlearning & Initial Noise Optimization (InitNO)

This repository contains research implementations focusing on two primary tasks:
1. **Machine Unlearning and Adversarial Verification in Generative Models (CVAE)**: Training a Conditional Variational Autoencoder on MNIST, exploring its latent geometry, selectively unlearning a digit class using Fisher Information (Selective Amnesia / EWC penalty), and subjecting the unlearned model to three distinct adversarial verification attacks (label manipulation, latent interpolation, and condition optimization).
2. **Initial Noise Optimization (InitNO) for Diffusion Models**: Enhancing multi-object composition and attribute binding in text-to-image diffusion models (`CompVis/stable-diffusion-v1-4`) by optimizing the initial latent noise using cross-attention, self-attention, and KL divergence objectives before generation.

---

## Task 1: Conditional Variational Autoencoder (CVAE) & Machine Unlearning

Implemented in [`task.ipynb`](task.ipynb).

### 1. CVAE Architecture & Baseline Training
- **Model Architecture**:
  - **Encoder**: Fully connected layers (`784 + 10` $\to$ `512` $\to$ `256`) projecting to latent parameters $\mu, \log \sigma^2 \in \mathbb{R}^8$.
  - **Decoder**: Fully connected layers (`8 + 10` $\to$ `256` $\to$ `512` $\to$ `784`) followed by Sigmoid activation.
  - **Loss Function**: Binary Cross Entropy (BCE) reconstruction loss + Kullback-Leibler Divergence (KLD).
- **Training**: Trained on MNIST with batch size 256; the best-performing checkpoint is stored at `checkpoints/best_model.pt`.

### 2. Latent Space Exploration
- Latent means and labels are computed across dataset batches and saved to `all_mu_mix.npy` and `all_labels.npy`.
- **Digits Distribution** (`digits-distribution.png`): Visualizes the clustering of different digit representations in the latent manifold.
- **2D Interpolation** (`2D-interpolation.png`): Bilinear interpolation on a $15 \times 15$ grid across selected digit anchor coordinates (`z_2d.npy`).

### 3. Class Unlearning via Fisher Information (Selective Amnesia)
- **Target**: Unlearn digit class `4` from the trained CVAE while preserving generative capabilities on remaining classes (`0-3`, `5-9`).
- **Fisher Information Matrix Calculation**:
  - Evaluates parameter importance using empirical Fisher Information on MLE parameters:
    $$F_i = \frac{1}{N} \sum_{n=1}^N \left( \frac{\partial \mathcal{L}_n}{\partial \theta_i} \right)^2$$
  - Saved to `fisher_data.pth` containing both `fisher_dict` and `params_mle_dict`.
- **Unlearning Optimization**:
  - **Retain Loss**: Enforces consistency on retained classes using pseudo-samples generated by a frozen pre-trained teacher clone (`model_clone`).
  - **Forget Loss**: Drives the forgotten class condition towards unstructured noise (`torch.rand`).
  - **Elastic Weight Consolidation (EWC) Regularizer**: Penalizes deviations from optimal weights proportionally to their Fisher importance:
    $$\mathcal{L}_{\text{ewc}} = \sum_i F_i (\theta_i - \theta_{\text{MLE}, i})^2$$
  - The final unlearned model weights are saved to `cvae_unlearned.pth`.

### 4. Adversarial Verification Attacks
To rigorously test whether knowledge of class `4` was genuinely eradicated or merely suppressed, three adversarial attacks are tracked across unlearning steps:

1. **Soft-Label (Label Manipulation) Attack**:
   - Interpolates the one-hot condition vector $y$ between the forgotten label ($4$) and an adjacent remembered label ($9$):
     $$y_\alpha = (1 - \alpha) y_{\text{forget}} + \alpha y_{\text{remember}}$$
   - Assesses whether boundary soft-conditioning reconstructs features of the forgotten digit.
   - Summary results saved to `attack_outputs/label_manipulation_SUMMARY.png`.

2. **Latent Interpolation Attack**:
   - Interpolates between two random latent vectors $z_1, z_2 \in \mathbb{R}^8$ conditioned on the forgotten class.
   - Probes the decoder's latent response space to observe if any regions retain the generative manifold of digit `4`.
   - Summary results saved to `attack_outputs/latent_interpolation_SUMMARY.png`.

3. **Condition Optimization Attack**:
   - Trains a convolutional surrogate classifier (`MNISTClassifier`) on MNIST to serve as an evaluation oracle.
   - Uses gradient ascent on continuous conditioning vector $y$ and latent vector $z$ to maximize the surrogate's predicted probability of class `4`:
     $$\max_{z, y} P(\text{class} = 4 \mid \text{Decoder}(z, \text{softmax}(y)))$$
   - Evaluates whether adversarial optimization can recover the unlearned class from the frozen unlearned decoder.
   - Summary results saved to `attack_outputs/condition_optimization_SUMMARY.png`.

## Task 2: Initial Noise Optimization (InitNO) for Diffusion Models

Implemented in [`initno.ipynb`](initno.ipynb).

### 1. Motivation
Text-to-image diffusion models often suffer from attribute binding errors and missing objects when conditioned on multi-subject prompts (e.g., "a giraffe and a tree", "a cat and a dog", "a rabbit and a turtle"). InitNO addresses this by optimizing the initial latent noise $z_T \sim \mathcal{N}(0, I)$ prior to the reverse denoising process.

### 2. Core Methodology
- **Base Architecture**: Pretrained `CompVis/stable-diffusion-v1-4` UNet, CLIP Text Encoder (`openai/clip-vit-large-patch14`), and `DDIMScheduler` (50 inference steps).
- **Custom Attention Processor (`AttentionProcessor`) & Store (`AttentionStore`)**:
  - Intercepts and records cross-attention maps (between spatial latents and text token embeddings) and self-attention maps (spatial-to-spatial features).
- **InitNO Loss Formulation (`compute_initno_loss`)**:
  - **Cross-Attention Loss ($\mathcal{L}_{\text{cross}}$)**: Identifies top spatial activations for target tokens and enforces cross-attention salience to ensure all specified subjects receive sufficient spatial focus.
  - **Self-Attention Loss ($\mathcal{L}_{\text{self}}$)**: Computes normalized cosine similarity between attention maps of distinct subjects to prevent semantic overlap and attribute entanglement.
  - **KL Divergence Regularizer ($\mathcal{L}_{\text{KL}}$)**: Ensures the optimized initial latent vector remains close to the standard Gaussian distribution $\mathcal{N}(0, I)$ to maintain generation photorealism and sample quality.
  - Combined loss:
    $$\mathcal{L}_{\text{InitNO}} = w_{\text{cross}} \mathcal{L}_{\text{cross}} + w_{\text{self}} \mathcal{L}_{\text{self}} + w_{\text{kl}} \mathcal{L}_{\text{KL}}$$
- **Optimization Loop (`initno_optimization`)**:
  - Freezes UNet parameters and runs Adam optimization directly on the latent variable $z_T$ across timesteps before final DDIM sampling.

### 3. Visual Comparisons
The directory `initno_outuputs/` contains side-by-side comparison images demonstrating generations from:
- **Left**: Standard random initial noise (often omitting subjects or improperly mixing attributes).
- **Right**: InitNO-optimized initial noise (correctly grounding multiple subjects and binding attributes).

Evaluated prompts include:
- `"a cat and a dog"` (`initno_outuputs/a_cat_and_a_dog*.png`)
- `"a giraffe and a tree"` (`initno_outuputs/a_giraffe_and_a_tree.png`)
- `"a rabbit and a turtle"` (`initno_outuputs/a_rabbit_and_a_turtle*.png`)
- `"a red backpack and a black suitcase"` (`initno_outuputs/a_red_backpack_and_a_black_suitcase*.png`)
- `"a squirrel with a hat"` (`initno_outuputs/a_squirrel_with_a_hat*.png`)
